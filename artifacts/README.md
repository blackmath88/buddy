# Real render evidence

2026-11-14. Generated by `e2e/evidence.spec.ts` against the actual built Buddy app, mounted at `/buddy/` in headless Chromium 156.0.8078.79. No artwork service or fabricated screenshot was used.

`gallery.png`, `studies/`, `buddies/`, `techniques/`, the two fidelity triptychs, mixer, comparison, portrait and weather/light captures are browser screenshots. `atlases/` are actual PNG downloads from the mixer export. `study-contact-sheet.png` and `technique-strip.png` are resized/labelled compositions of those screenshots, made with `scripts/contact-sheets.py`.

The original autumn capture is the unchanged historical study, separate from the new renderer. Its source-rights notes remain applicable.

`browser-results.json` is the final production browser report. `performance.json` records a named, unpaused, two-renderer sampling run; RAF intervals are not a CPU benchmark or physical-device promise. `build-size.json` records exact built app file and gzip lengths, excluding copied historical references, documentation and these evidence images.

Reproduce:

```sh
npm ci
npm run build
LAB_PRODUCTION=1 npm run test:browser
python3 scripts/contact-sheets.py
npm run measure
```

Install the Playwright Chromium browser first, or set `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` to an installed executable. Python/Pillow is optional for composing sheets. Tests start and stop the test server. The screenshot suite uses reduced-motion/still captures, then explicitly resumes animation before its performance sample.
